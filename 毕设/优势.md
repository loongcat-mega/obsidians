对比于端到端的深度学习模型方法，本文方法具有多方面的优点：第一，传统动态手势识别模型多数是基于端到端的方法训练，往往需要大量标注数据才能实现模型的稳定，而且模型结构较复杂，很难达到很好的精度。所以在引入新的手势之后，就需要重新采集样本，然后根据新的样本再进行模型的训练，重新训练花费的精力较多，况且最终结果不一定满足要求；第二，本文采用的方法只需要增加在静态识别模型中对新手势的支持，并且给定状态机中对应的增加了新的状态即可，相较于传统的手工方式大大降低了整个方法的开发成本；第三，在计算资源方面本文方法也将复杂的时序建模问题分解为两个相对简单的过程：静态识别及状态转移，由于二者均可采用轻量化的方式实现，因此方法就可以很容易地在各种低端甚至嵌入式设备中得到实现。

时空分离，使设计更加简单，静态手势使用mediapipe识别，首先使用目标检测模型定位手掌位置，然后回归计算出手部21个关键点信息，进行静态手势识别。静态手势识别是空间空间特征的计算。动态手势使用单次激活算法和状态机的设计，是时间特征，单次激活算法的核心思想是手势出现与手势重复，使用了两个阈值来表示，分别是手势识别准确率阈值与手势重复计数阈值，只有当手势识别准确率达到准确率阈值，并且手势重复次数达到计数阈值才可视为一个静态手势。该算法主要是为了解决在连续帧中穿插多个不相干手势的情况，减少了手势快速变换的微扰。状态机包含了过往时间段的识别结果，并根据识别出的手势与过往结果去匹配状态转移表。

def shift(self, gesture):  
# 1. 跳过空手势，防止空手势对状态机产生影响  
if gesture is None or gesture == "" or gesture == constants.NONE:  
    self.none_gesture_frames += 1  
    return  
# 2. 首次进行状态转换,，更新状态机历史状态  
if self.gesture_seq.empty():  
    self.gesture_seq.add(gesture)  
    return  
  
# 3. 判断是否满足单次激活条件  
if not self.single_time_activation(gesture):  
    return  
print(f"满足单次激活:{gesture}:{self.gesture_seq_cnt[gesture]}")  
# 4. 进入状态转移,并重新对手势持续帧数进行计数  
self.gesture_seq_cnt[gesture] = 0  
self.shift(gesture)  
print(self.gesture_seq.all())  
# 5. 如果同一个手势持续了30帧或者空手势持续了30帧，则重置状态机  
if self.dynamic_gesture_frames >= constants.FPS or self.none_gesture_frames >= constants.FPS:  
    self.reset()
